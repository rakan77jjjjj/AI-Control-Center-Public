# تعليمات الوكلاء | Agent Instructions

اقرأ `DOCUMENTATION_LANGUAGE_POLICY_AR_EN.md` قبل إنشاء أو تحديث أي توثيق.
Read `DOCUMENTATION_LANGUAGE_POLICY_AR_EN.md` before creating or updating documentation.

## اللغة | Language
- كل محتوى بشري جديد أو معدّل في GitHub يجب أن يكون بالعربية والإنجليزية معًا، والعربية أولًا، بالمعنى نفسه في اللغتين.
- All new or edited human-facing GitHub content must be bilingual (Arabic + English), Arabic first, with equivalent meaning.
- يشمل ذلك README وIssues وPull Requests والتعليقات وخطط العمل وتقارير الحالة وأدلة التشغيل والاختبار.
- This includes README, issues, pull requests, comments, plans, status reports, and run/test guides.
- لا تترجم أسماء الملفات والمسارات والفروع والمعرفات البرمجية ومفاتيح البيانات وأعلام CLI وأوامر الطرفية أو رسائل الخطأ الحرفية.
- Never translate filenames, paths, branches, code identifiers, data keys, CLI flags, terminal commands, or exact error strings.
- عند تحديث وثيقة قديمة، اجعل الجزء الذي تلمسه ثنائي اللغة وحافظ على الروابط والأوامر والمعنى.
- When updating an old document, make the section you touch bilingual and preserve links, commands, and meaning.

## جودة العمل | Work quality
- اذكر الهدف والحالة وما اكتمل وما بقي والعوائق والخطوة التالية.
- State the goal, status, completed work, remaining work, blockers, and next step.
- لا تدّع نجاح اختبار أو نشر دون دليل فعلي.
- Never claim a test or deployment succeeded without actual evidence.
- لا تكشف أسرارًا أو مفاتيح أو بيانات خاصة في مستودع عام.
- Never expose secrets, keys, or private data in a public repository.
- لا تغيّر الكود أو المخطط أو المعرفات التقنية لمجرد التعريب.
- Do not change code, schemas, or technical identifiers merely for localization.
