AI Control Center مشروع أبنيه ليكون مكانًا واحدًا على ويندوز يجمع الذكاء المحلي، الذاكرة، المشاريع، التدريب والأدوات، مع بقاء المستخدم هو صاحب القرار في الصلاحيات والملفات والاتصال بالإنترنت.

المشروع على GitHub وش الموجود الآن؟
الحالة الحالية 4.7.1 Beta

العمل الجاري الآن على 4.8: التدريب الحقيقي للـStudent ونظام تحديث يحافظ على بيانات المستخدم.

المشكلة التي أحاول حلها

ما أبي الذكاء يكون مجرد صندوق محادثة. أبي بيئة أقدر أربطها بمشاريعي وأدواتي، لكن بدون أن أعطي الموديل وصولًا مفتوحًا للجهاز.

Task ↓ Project Context ↓ Allowed Files / Tools ↓ Permission Check ↓ User Approval when needed ↓ Execution + Audit

وش وصل له المشروع؟

ذكاء محلي

دعم تشغيل نموذج محلي مع توجه Local-first بدل الاعتماد الإجباري على خدمة سحابية.

ذاكرة وبيانات محلية

بيئة المستخدم وذاكرته وملفاته لا تأتي مدمجة مع النسخة العامة.

إدارة مشاريع

أساس للتعامل مع المشاريع ومساحات العمل بدل محادثة منفصلة بلا سياق.

Teacher + Dataset

نظام يبني أمثلة تدريب ويجهز Dataset قبل مرحلة تدريب الـStudent.

تجهيز التدريب

بيئة تدريب منفصلة وفحوصات GPU وCUDA وتجهيز أولي لـLoRA / QLoRA.

Action Router

الموديل يطلب الفعل، والنظام يتحقق من الصلاحية والموافقة قبل التنفيذ.

Git وGitHub

أساس للتعامل مع المشاريع والإصدارات وسجل التغييرات.

Setup Manager

تجهيز المكونات الاختيارية بدل فرض كل الاعتماديات على المستخدم من البداية.

Windows Installer

المشروع يستهدف تجربة تطبيق سطح مكتب على ويندوز بدل تشغيل مجموعة سكربتات يدويًا.

الأمان قبل القوة

من القرارات الأساسية في المشروع: لا يتم تمرير كلام الموديل مباشرة إلى PowerShell أو CMD.

AI ↓ Action Router ↓ Permission Check ↓ Owner Approval ↓ Execution ↓ Audit Log

الخصوصية

النسخة العامة لا تأتي مع ذاكرتي الشخصية أو مشاريعي أو Dataset الخاص بي أو مفاتيحي. كل تثبيت يبدأ ببيئته الخاصة، وأي خدمة خارجية أو صلاحية إضافية تكون باختيار المستخدم.

وش جاي بعد؟

4.8 — Real Training + Updates

اختيار Base Model، تدريب LoRA / QLoRA حقيقي، Progress وEpoch وStep وLoss، مراقبة VRAM، Safe Stop، Checkpoints، حفظ Adapter، واختبار النموذج قبل وبعد التدريب. بالإضافة إلى Backup / Verify / Update / Rollback مع الحفاظ على بيانات المستخدم.

4.9 — Stable Foundation

تركيز على الثبات، First Run، الأخطاء، الـInstaller، اختبار الأجهزة النظيفة، والتأكد أن كل وظيفة ظاهرة للمستخدم تعمل فعلًا.

كيف أبنيه؟

أخطط المشروع وأوثق قراراته ومراحله، أطور وأختبر على ويندوز، وأستخدم أدوات الذكاء الاصطناعي للمراجعة والبرمجة وحل المشاكل مع إبقاء Git وسجل الاختبارات والقرارات كمرجع للعمل.

الأدوات المستخدمة تشمل Python، Git، GitHub، نماذج محلية عبر Ollama، وأدوات ذكاء اصطناعي مثل ChatGPT وClaude للمساعدة في التطوير والمراجعة.
